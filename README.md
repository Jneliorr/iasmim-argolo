# Iasmin Argolo · Nutrição

Landing page em React, TypeScript, Vite e Tailwind CSS, com animação WebGL nativa.

## Executar

```sh
npm install
npm run dev
```

## Gerar a versão de produção

```sh
npm run build
npm run preview
```

Conteúdo e links: `src/content.ts`. Estilos responsivos: `src/styles.css`. Fotografias fornecidas pela cliente: `public/images/`.

A foto do destaque principal é a primeira imagem da publicação indicada pela cliente: https://www.instagram.com/p/DecuWBVkbn3/. O arquivo `iasmin-atendimento-instagram.jpg` foi obtido da própria publicação, preservando a composição original.

Identidade: `public/brand/iasmin-argolo-logo.png` contém a restauração em alta resolução e com transparência do logo fornecido. `public/brand/iasmin-argolo-simbolo.png` contém o abacaxi isolado. Aplicações: cabeçalho, rodapé em versão clara via CSS, abertura, detalhes de marca e favicon. Os arquivos foram preparados com ImageGen; a assinatura é uma reconstrução visual da referência de baixa resolução. Briefs de edição em `brand-prompts.md`.

As áreas de atendimento foram extraídas do texto da fotografia fornecida. Dicas gerais de alimentação possuem referência ao Guia Alimentar do Ministério da Saúde. Os botões de agendamento direcionam ao Instagram informado.

A localização utiliza o código oficial de incorporação obtido em Compartilhar > Incorporar um mapa no Google Maps. O endereço e os trechos de três avaliações reais foram conferidos no perfil público em 27/10/2026. A nota e a quantidade de avaliações representam essa consulta e não se atualizam automaticamente. Os cartões identificam os autores, sinalizam que são trechos e levam ao perfil original. CRN e horários não foram adicionados.
